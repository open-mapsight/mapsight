The standard `toilet` icon uses `fa-restroom`; `toilet-accessible` combines `fa-restroom`
and `fa-wheelchair`. Mapsight scales, positions and colors these glyphs inside
its own shared marker frame. The optional `fa-*` pack uses the same source and
license. Generated modules and composed SVGs retain attribution to Font Awesome.
