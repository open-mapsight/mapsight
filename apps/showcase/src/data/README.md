# Fictional showcase fixtures

`demo.geojson` is generated deterministically by
`node /home/pje/Sites/mapsight-worktrees/showcase-scenarios/apps/showcase/scripts/scenario-data/generate-demo.mts`.
It has the charging-station demo's property schema, but contains only invented
names, descriptions and positions on a regular grid inside the allowed tile bbox.
No real addresses, operators, customer markup or remote image references are used.
The repository MIT licence applies. This is not an operating charging network.
