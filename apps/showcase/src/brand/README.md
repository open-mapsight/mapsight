# Mapsight brand assets

The Mapsight marks (horizontal lockups and favicon) are not MIT licensed. Their
use follows [the trademark policy](../../../../docs/TRADEMARK.md).

`tokens.css` is copied verbatim from the brand system **1.0.0-rc.1**, under MIT
(see `LICENSE-tokens.txt`). The shell rewrites only its `:root` selectors to
`.msb-shell` when loading it, so even token declarations stay within the frame.
No product `--ms3-*` roles are changed.

Overpass and Overpass Mono are self-hosted under the SIL Open Font License;
licences are included in `fonts/`. Brand fonts apply only to shell elements and
landing/legal content, never to the product outlet. Theme state is in memory
only and starts with the OS preference; it does not change the product theme or
use storage.

## Shared website header

`site-header.css` is the single layout source for the official project website
(both languages) and showcase. Use its `msb-site-header__*` classes with a header,
inner container, mast (brand and tools) and navigation list. The descriptor is
optional; logo size, baseline, gutters, breakpoints, tools and navigation are
shared. All navigation states retain the same weight and dimensions; the current
page uses `aria-current="page"` and an underline. Do not add consumer-specific
header overrides to `global.css` or the website stylesheet.

The website builder reads these files directly from a Mapsight checkout using
`MAPSIGHT_SOURCE_DIR`, stages a disposable build cache and hashes the local assets
into its output. It fails if this shared source is absent. No separately edited
website copy or runtime request to another domain is involved. The private brand
workspace and its non-web templates remain separate.

Both builds publish `/web-brand.json`, generated by
`../../scripts/web-brand.mts`, with SHA-256 hashes of the shared header, tokens,
marks, fonts and licence files. Matching manifests identify the same web identity.
Build both surfaces from the same revision when changing it. The website's
`scripts/check-web-header.ts` compares real builds at 320/360/768/1280 px in both
themes, checks matching logo/grid geometry and detects navigation movement.
The showcase's `e2e/brand-shell.spec.ts` also checks navigation and theme stability
in CI, including the standalone scenarios overview.
