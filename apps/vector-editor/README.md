# `@mapsight/vector-editor`

Vector editor for creating and editing vector features, exported as GeoJSON.

## Commands

From the monorepo root:

```bash
pnpm --filter @mapsight/vector-editor dev
pnpm --filter @mapsight/vector-editor build
pnpm --filter @mapsight/vector-editor start
```

- `dev` — compile the vector style, copy traffic-style icons, then start Vite
- `build` — production Vite build (after style compile + icon copy)
- `start` — preview the production build

See the [documentation hub](../../docs/README.md) for broader Mapsight integration guides.
