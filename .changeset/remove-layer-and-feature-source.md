Add `removeKey(path)`, `removeLayer(controllerName, layerId)` and `removeFeatureSource(controllerName, id)` so a host application can remove a single layer or feature source at runtime. `removeLayer` leaves the layer's feature source and all selections untouched, and releases what the layer's vector source subscribed to: it no longer fits the map or syncs features after the layer is gone (also when a layer object is replaced), while other layers on the same feature source keep working. Reducers, controllers and selectors now skip `undefined` layer and source entries, so `unset` of a layer or source no longer throws. Actions addressed to a feature source id that is not in the state are now ignored (`setData`, `setError`, `loadSuccess`, `loadFailure`, `pauseRefreshUntilNextLoad`, feature edits, `undo` and `redo`); before, `setData`, `loadSuccess`, feature edits and `undo`/`redo` threw for unknown ids, while `setError`, `loadFailure` without a request number and the pause action created a partial source. Create a source through configuration before you write to it. Requires the matching `@mapsight/lib-redux` release.
