Add the opt-in `@mapsight/ui/plugins/browser/view-permalink` plugin, which keeps the map view (`#map=zoom/lat/lon[/rotation]`) and the visibility of switchable layers (`layers=id,id`) in the page address so a copied link reopens the same view. Hosts add it to their plugin list; it is not part of the default browser plugins.
