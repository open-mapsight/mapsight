UI surfaces can follow a dark host theme. Set `$ms3-future-v8-themedSurfaces: true` with the other `@mapsight/ui` Sass variables to take the colours that were fixed to light values from the `--ms3-*` tokens: the `.ms3-wrapper` background (`--ms3-page-background-color`), the attribution box, tool overlay, mini legend, link share field, button and icon, list search input, search reset circle, disabled pagination text, marked point coordinates, map point menu border, and the translucent map controls on narrow screens (new optional `--ms3-map-control-background-color`, default `--ms3-background-color` at 90 % opacity). `.ms3-wrapper` follows the page's `color-scheme` unless the host sets the new optional `--ms3-color-scheme`, and buttons, inputs and selects without their own colour inherit the text colour instead of the browser default. The default stays unchanged: without the flag the compiled CSS is identical to before.

When you opt in: hosts that already set `--ms3-background-color` or `--ms3-page-background-color` to a non-white value see it on these surfaces; form controls that Mapsight does not colour take the inherited text colour instead of `buttontext`/`fieldtext`; and in the default theme four near-duplicate greys change slightly (link share field `#444` on `#f5f5f5` to `#222` on `#f2f2f2`, disabled page and coordinates `#555`/`#5c5c5c` to `#636567`, search reset circle `#eee` to `#f2f2f2`). Dark themes also need a light text colour on the page or wrapper and should set `--ms3-focus-ring-color` and `--ms3-attributions-background-color`. See [Themed surfaces and dark host themes](https://github.com/open-mapsight/mapsight/blob/main/packages/ui/README.md#themed-surfaces-and-dark-host-themes-ms3-future-v8-themedsurfaces). The flag becomes the only behaviour in v8.
